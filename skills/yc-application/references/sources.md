## Not verified, so not used for rules
- The current (2026) application form's exact questions and character limits: the form needs a login.
- The full YC Interview Guide body: the page didn't load during research.
- PG's "Default Alive or Default Dead", "Startup = Growth" and "How to Convince Investors": these couldn't be fetched, so nothing is cited from them.
- Interview question lists compiled by third parties (e.g. TechCrunch 2012): used only where accepted founders independently reported the same questions.
